AI DEVELOPMENT PROCESS

AI Tools & Prompts

05

AI Tools Used

ChatGPT

I used ChatGPT to help generate the initial website code, improve the design and layout, add Billkin's albums, songs, and acting works, fix coding and layout problems, and guide me through deploying the website to GitHub Pages.

Prompt 1

"Create me a website about Billkin's work by using Python code."

What I changed

I created the first version of the website using Python Flask. The website included a homepage, an About section, selected acting works, and a music section. I also used HTML for the page structure and CSS for the design.

Prompt 2

"I use Cursor. Show me step by step."

What I changed

I opened the project in Cursor and organized the website into app.py, templates/index.html, static/style.css, and an images folder. I also learned how to install Flask and run the website locally.

Prompt 3

"I want it to be with pictures."

What I changed

I added a main Billkin image to the hero section. I also added images for his acting works such as I Told Sunset About You, I Promised You the Moon, How to Make Millions Before Grandma Dies, and The Red Envelope.

Prompt 4

"I want it to be with all album and all songs."

What I changed

I expanded the music section by adding Billkin's albums, EPs, singles, OSTs, collaborations, and live sessions. I also added tracklists under each album instead of only showing a few selected songs.

Prompt 5

"Update from this code."

What I changed

Instead of creating a new website, I continued working from my existing app.py, index.html, and style.css. I kept the same design and added the new album and song information into the existing website.

Prompt 6

"I want to put pictures into the album section."

What I changed

I added album cover images to each album card. Each card now contains the album cover, release year, release type, album name, and complete tracklist.

Prompt 7

"Why are the rest of the album pictures big? Fix it."

What I changed

I fixed the album layout because some images were stretching across the whole webpage. I corrected the HTML structure and used a two-column CSS grid so every album cover has a consistent size.

Prompt 8

"Change 'Stories that stay. Music that moves.' to something else."

What I changed

I changed the closing message to better match the theme of Billkin's music and acting career. This helped make the ending of the website feel more connected to the rest of the content.

Prompt 9

"How do I deploy this website to GitHub Pages?"

What I changed

Because GitHub Pages cannot directly run Flask, I used Frozen-Flask to convert the Flask website into static HTML, CSS, and image files. The generated website was saved inside a docs folder.

Prompt 10

"I want to put it in my existing repository."

What I changed

I placed the generated docs folder inside my existing GitHub repository and configured GitHub Pages to deploy from the main branch and the /docs folder. This created a public website link that can be shared with others.
