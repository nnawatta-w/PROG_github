BILLKIN WORKS — Flask Website
=============================

1. Open Terminal in this folder.

2. Create/activate your environment if needed.

3. Install Flask:
   pip install flask

   Or with uv:
   uv add flask

4. Run:
   python app.py

5. Open the local address shown in Terminal, usually:
   http://127.0.0.1:5000

Files:
- app.py                  Python / Flask
- templates/index.html    Website structure
- static/style.css        Website design
